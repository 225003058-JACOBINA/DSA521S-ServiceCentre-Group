## How to run
1. Open the project folder in VS Code or any Java IDE.
2. Compile all files: javac *.java
3. Run: java Main
4. Follow the on-screen menu (options 1-11).

IMPORTANT: PostfixEvaluator.java and SortingAlgorithms.java also each have their own main() 
method and can be run independently to see Task A3 and Task B demonstrated in isolation.
